# Reference-led frontend revision

The selected visual target is `design-reference/homepage-desktop-mobile-concept.png` (desktop panel and phone content). This revision corrects the first implementation's editorial redesign.

Changed: compact wordmark-led hero with separate decorative botanical profile; panoramic peach/pink mixed bouquet and textured ivory background; rose CTA; six occasion tiles; five rounded product cards on desktop and two on mobile; individual rose, pink, sunflower, lily and mixed demo images; functional favorite toggles; watercolor ordering strip; compact branch cards and floral closing panel. Header typography, spacing and active navigation now follow the reference's boutique serif treatment. The mobile hero stays side by side and the occasion row scrolls horizontally.

Commerce rules, order API disabled state, Supabase foundation and checkout flow were preserved. Demo occasion tags allow Love & Romance and Get Well Soon tiles to filter appropriate existing demo records. No live catalog items were introduced.

Deliberate content differences: demo disclosure; sample prices; no invented ratings, best-seller claims, verified stock, GrabMart integration, fixed cutoff or branch photographs. Address and hours claims remain pending verification. The decorative motif is generated concept art, not an approved official logo. Functional content and legal/privacy navigation remain available in the footer and supporting pages.

Generated assets are in `public/images/`. The original supplied poster/reference files remain unchanged. No production payments, live orders or deployment were enabled.
